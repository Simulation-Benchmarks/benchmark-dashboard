User guide

This dashboard groups published simulation runs by benchmark, lets you inspect benchmark metadata, and helps you compare runs from the same benchmark in one place.

Using the dashboard

1. Choose a benchmark

Use the top Benchmarks table to select a benchmark family. The lower Published runs table updates to show only runs for the selected benchmark.

2. Inspect metadata

Click the metadata button in the benchmark table to load the benchmark definition and view its parameter and metric names. Metadata is loaded on demand and reused after the first request.

3. Explore published runs

Search the runs table by software name, open RoHub or named-graph links, and reload the published-run list when you want to bypass the API cache.

4. Compare runs

Select at least two runs from the same benchmark and use Compare to open the analysis dialog with shared parameters, metrics, tables, and plots.

5. Review SPARQL activity

Open Logs to inspect the live SPARQL queries executed by the backend, copy them, and run them directly on the RoHub SPARQL endpoint if needed.
